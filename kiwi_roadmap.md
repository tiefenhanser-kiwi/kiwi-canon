## Recipe catalog & wizard-freshness plan (Hans-ruled July 6, 2026)

**Origin:** AI cost at scale (~$0.40–0.70/plan, dominated by the Sonnet expansion stack — ~$2,000–3,500/mo at the 1K-user scenario; cross-ref D-WS7-077) plus UX complaints: repetitive plan names ("Mexican Fiesta Week"), same meals week after week, single-cuisine plans. Catalog-select generation drops cost to roughly **$0.02–0.08/plan on catalog hits** (recipes pre-expanded, macros pre-computed) and fixes repetition structurally.

**Phase A — Wizard prompt tuning (prompt-body-only; July 9: rides alongside the Phase B close inside the WS7-8 wrap, or parks as a WS9-downtime block; pairs with D-WS7-166/-167):**
- Unique/variable plan names (kill the "Cozy Comfort Meals Week" repetition).
- Recently-used/cooked meal exclusion — server injects ~4 weeks of the user's plan/cook history as hidden context; reusing ~1 meal/week is fine, more is not.
- Cuisine spread: ~one meal per preferred cuisine; 2+ of the same cuisine is fine for ingredient sharing or when preferred cuisines < plan days.
- Season/date awareness injected into the prompt (no API needed) + a static holiday/event calendar table (Cinco de Mayo, Memorial Day cookout, NFL/baseball season, etc.).
- Weather context when the go-live weather-API item lands (`kiwi_go_live_todos.md` — NWS + IP geolocation, no zip-code signup friction).

**Phase B — Preference changes (small block, grown per July 6 rulings; July 9: IN PROGRESS — Hans building; closes inside the WS7-8 wrap. Built pre-restyle, so the WS9 wizard/preferences block gets a spec delta covering these controls before that block commissions):**
- Remove `wantsLeftovers` from the screen (D-WS7-190 — backend stays; deprecate-vs-reuse ruled later; check against the `effectiveServings` keystone).
- Add "Try something new": `discoveryMealsPerWeek: 0 | 1 | 2` — toggle + segmented control (1 meal / 2 meals a week), helper copy "Kiwi will add a wild card or two — meals outside your usual cuisines and favorites, so you discover new food." Generation rule: N meals outside preferred cuisines and outside recent history.
- Add sauces & seasonings preference (Hans-ruled July 6): `saucePreference: 'store_bought' | 'balanced' | 'homemade'`, default `balanced`. UI: "Sauces & seasonings — When a meal calls for a dressing, marinade, or spice blend, should Kiwi go store-bought or homemade?" Options: **Grab the bottle** (store-bought whenever it exists) / **Mix it up** (store-bought for the complicated stuff, homemade when it's fast) / **From scratch** (homemade whenever practical). Three levels, not four — each maps to a concrete generation rule. Side benefit: "Grab the bottle" shortens grocery lists and prep steps (friction priority).
- Add cook-time cap (Hans-ruled July 6 — this is the **D-WS7-166 design ruling**; log-entry annotation queued for the deferral log's next touch): `maxCookTimeMinutes: 30 | 45 | 60 | null` + `maxCookTimeCoverage: 'all' | 'most'`. Reads against the wizard contract's existing `estimatedTimeMinutes`; "most" coexists with weekly pacing (`one_fancy_night` + a cap on the rest).
